Compléments INSEE (hors sujet)

Version 1.0 — 2026-08-24

Principe

Le fichier pédagogique territoire_insee.csv du sujet n’est jamais modifié. Un second fichier data/external/territoire_insee_complements.csv ajoute des colonnes préfixées INSEE_ajoute_*, jointes sur Commune + CodePostal.

Colonnes ajoutées

  • INSEE_ajoute_CodeCommune — code COG
  • INSEE_ajoute_PopulationLegale — population légale (millésime 2021)
  • INSEE_ajoute_PartPlus65Ans_pct — part des 65 ans et plus
  • INSEE_ajoute_Departement / Region
  • INSEE_ajoute_EcartPop_vs_sujet — audit qualité (sujet − INSEE)

Registre

Colonne origine_donnee : sujet | insee_ajoute | derive_affichage.

Les compléments INSEE sont exposés dans la webapp (fiche lit). Ils ne sont pas encore injectés dans le modèle ML entraîné (évite de casser le bundle).

Accessibilité

Dans l’UI, deux cartes distinctes « Données du sujet » / « INSEE ajouté » (couleur + titre, pas la couleur seule).
