Webapp de démo locale

Version 0.9.2 — 2026-09-01

Design system

Interface Clinical Precision (maquettes Stitch dans stitch_refonte_logiciel_hospitalier/) : sidebar fixe, palette teal #003735, Inter + JetBrains Mono, cartes à bordure légère, badges de statut clinique.

Rôle

Deux parcours séparés depuis le hub / :

  • Parcours CISIA (/cisia) : score de réadmission 30 j, facteurs SHAP, justification, registre, biais
  • Démo soignant (/soignant) : plan d’étages (sections dépliables par étage), liste des lits (/soignant/lits), constantes simulées — illustration hors brief principal
  • Affichage patient : nom de famille + sexe uniquement
  • Fiche CISIA : ordre score → SHAP → justification → CR masqué → contexte → territoire
  • Page biais : écarts par sexe / âge / défavorisation
  • Sur l’étage : badge proba 30 j + lien vers fiche CISIA
  • Redirections : /sejours et /registre → équivalents /cisia/…

Sécurité

  • Bind 127.0.0.1:8000 uniquement
  • Pas de prénom affiché ; CR masqués avec [PATIENT]
  • Compléments INSEE = proxies agrégés, hors identité individuelle

Lancer

PYTHONPATH=. python scripts/run_pipeline.py
PYTHONPATH=. python scripts/train_models.py
PYTHONPATH=. python scripts/run_webapp.py
# ouvrir http://127.0.0.1:8000

API lits (soignant)

GET /api/lits — recherche AJAX avec paramètres q, etage (0–4), service, sexe, page, page_size. Réponse JSON paginée (total, items, filters).

Parcours jury

Route /cisia/jury — démo guidée en 5 étapes pour présentation CIF (~5 min) :

  • Hero avec KPI (étapes, séjours scorés, modèle retenu)
  • Stepper horizontal cliquable (?etape=1…5 + ancres #etape-N)
  • Encart privacy (LLM local, bind 127.0.0.1, données synthétiques)
  • Timeline verticale : carte par étape (badge icône, consigne « À faire », CTA primaire + lien étape suivante)
  • Footer : séjour d’exemple + bouton « Lancer le parcours guidé » (POST /cisia/demo/start)
  • Encart lancement : un clic pour démarrer, puis Entrée à chaque écran (barre de tutoriel)

Classes CSS dédiées : .jury-* dans webapp/static/styles.css.
