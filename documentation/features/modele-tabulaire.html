Modèle tabulaire

Version 0.1 — 2026-08-24 — entraînement 100 % local, données synthétiques.

Choix d’algorithme

  • Baseline : régression logistique (imputation, one-hot, standardisation, classes équilibrées).
  • Boosting : HistGradientBoostingClassifier (sklearn), profondeur 4. LightGBM natif écarté : bibliothèque libomp absente sur ce Mac.
  • Modèle retenu : celui qui a le meilleur PR-AUC sur le test (ici : logistique).

Seuil

Maximisation du F2 (β=2) sur la validation uniquement. Objectif hôpital : limiter les réadmissions non détectées.

Lancer

PYTHONPATH=. python scripts/run_pipeline.py
PYTHONPATH=. python scripts/train_models.py

Artefacts : models/*_metrics.json, *_biais.csv, *_shap.csv. Les .joblib restent hors git.
