Version 0.1 — 2026-08-24

Objectif

Auditer les 11 CSV, séparer le nominatif, construire deux jeux de features (score sortie / score télésurveillance) sans fuite temporelle.

Arborescence

  • data/raw — copies locales (hors git)
  • data/vault_identite — coffre nominatif (hors git)
  • data/pseudonymise — tables de travail
  • data/curated — parquets de features

Anti-fuite

  • Split par PatientID
  • Score sortie : horodatage ≤ date de sortie ; pas d’objets connectés
  • Score télé : fenêtre fixe de 7 jours, mesures QualiteSignal = Bon uniquement
