Fondation données

Version 0.2 — 2026-09-28

Objectif

Auditer les 11 CSV, séparer le nominatif, construire deux jeux de features (score sortie / score télésurveillance) sans fuite temporelle.

Registre extensible

Sources et étapes déclarées dans src/data/registry.py / pipeline_steps.py. Jupyter lit describe_pipeline() et sources_dataframe() — un nouveau bloc enregistré via register_pipeline_step apparaît sans réécrire les notebooks.

Arborescence

  • data/raw — copies locales (hors git)
  • data/vault_identite — coffre nominatif (hors git)
  • data/pseudonymise — tables de travail
  • data/curated — parquets de features

Anti-fuite

  • Split par PatientID
  • Score sortie : horodatage ≤ date de sortie ; pas d’objets connectés
  • Score télé : fenêtre fixe de 7 jours, mesures QualiteSignal = Bon uniquement

Lancer

./scripts/lance_environnement.sh
# Jupyter : http://127.0.0.1:8888/tree
# Point d’entrée : notebooks/00_guide/01_cadre_projet.ipynb (objectifs / cadre)
# Puis inventaire : notebooks/01_donnees/01_inventaire_sources.ipynb
# Analyse qualité : notebooks/01_donnees/05_analyse_donnees.ipynb
# (CSV → DataFrames → nulls/dates/patho — Run All)

PYTHONPATH=. python scripts/run_pipeline.py
PYTHONPATH=. pytest -v
