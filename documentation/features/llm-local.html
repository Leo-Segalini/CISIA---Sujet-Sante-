LLM local (comptes-rendus)

Version 0.2 — 2026-08-25

Choix

  • Préféré : Qwen/Qwen2.5-3B-Instruct-GGUF → qwen2.5-3b-instruct-q4_k_m.gguf (~2 Go) — meilleures justifications FR sur Mac 16 Go.
  • Repli : Qwen2.5-1.5B Q4_K_M si le 3B n’est pas téléchargé.
  • Runtime : llama.cpp en sous-processus CPU (stable) — aucune Inference API cloud.
  • Hub HF = téléchargement des poids uniquement ; les CR restent sur le poste.

Commandes

pip install huggingface_hub
# optionnel : HF_TOKEN pour les quotas Hub
CMAKE_ARGS="-DGGML_METAL=on" pip install llama-cpp-python
PYTHONPATH=. python scripts/download_gguf.py
PYTHONPATH=. python scripts/train_nlp.py

Les poids GGUF restent dans models/gguf/ (hors git).
